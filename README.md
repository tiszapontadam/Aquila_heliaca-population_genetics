# Aquila_heliaca-population_genetics

Code and data for manuscript on the population genetics and phylogeography of Aquila heliaca

Contents:

ABCrcode - Folder of R scripts for conducting Approximate Bayesian Computation (ABC) on genotypic data

FSC_models - .tpl files of hypothetical scenarios of Aquila heliaca demography for Fastsimcoal

genotype_data - GenAlEx compatible empirical microsatellite (SSR) and mitochondrial control region (Domain I) sequence data from Aquila heliaca populations used for the manuscript 'Anthropogenic fragmentation shapes recent genetic differentiation in the widespread but philopatric eastern imperial eagle Aquila heliaca'
